# Telegram 远程助手

Telegram 助手默认关闭。启用前请先通过 BotFather 创建自己的 Bot，并在影迹本机页面配置：

1. Bot Token；
2. 自己的 Chat ID 允许名单；
3. 可选代理；
4. 可选本地 Bot API 地址；
5. 可选翻译服务凭据。

安全建议：

- 不要把 Token 发到 Issue、日志截图或聊天群；
- 允许名单为空时不会接受远程下载；
- 每个 Chat ID 默认每分钟最多提交 6 次，同时最多保留 2 个未完成任务；
- 大文件回传失败时只提示本机文件名，不向 Telegram 泄露绝对路径；
- 本地 Bot API 仅允许 `127.0.0.1`、`localhost` 或 `::1`；
- 翻译服务的自定义地址必须解析到公网目标。

真实 Telegram 网络行为取决于 Token、账号、网络代理和 Telegram 服务状态。自动化测试只验证本地授权、脱敏、配额和失败边界，不包含真实账号端到端操作。
